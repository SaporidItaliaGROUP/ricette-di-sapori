# Pagine di esempio per le prove

Queste pagine **non sono copie di siti veri**: sono scritte a mano e imitano i modi
più comuni in cui i siti di cucina dichiarano una ricetta. Servono a provare la
lettura senza rete. Una prova passata qui **non garantisce** che un sito vero venga letto.

| File | Che cosa imita |
|---|---|
| `scheda-semplice.html` | Scheda diretta, come nei grandi siti italiani. |
| `scheda-wordpress.html` | Scheda dentro un «grafo» con più oggetti e passaggi divisi in sezioni (blog WordPress). |
| `scheda-francese.html` | Sito francese: accenti, elenco di schede, procedimento in un solo testo. |
| `scheda-sporca.html` | Dati scritti male: a capo dentro le frasi, commenti, codice HTML nei testi, foto con indirizzo relativo. |
| `etichette-vecchie.html` | Nessuna scheda: solo etichette «microdata» nel testo (siti più vecchi). |
| `scheda-povera.html` | Scheda con il solo elenco ingredienti, senza procedimento né tempi. |
| `senza-ricetta.html` | Un articolo di blog senza dati di ricetta. |
